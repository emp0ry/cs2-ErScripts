GETTING STARTED

A few steps.
Then your setup.

Follow the project’s setup instructions before your first run.

Full installation guide ↗
  1. 01

    Get the official build.

    Download ErScripts.exe from GitHub Releases and place it in a folder of your choice.

  2. 02

    Set CS2’s launch options.

    In Steam, open Counter-Strike 2 → Properties → General. Add these to Launch Options:

    -conclearlog -condebug +bind scancode104 exec erscripts1

  3. 03

    Start ErScripts, then CS2.

    On the first run, open ErScripts before the game. After that, it can start while CS2 is already running.

  4. 04

    Make it your own.

    Insert opens or hides the menu. End exits the app. Change either key under Menu → Custom Binds.

BEFORE YOU RUN IT

Know your setup.

An independent personal project for experimentation and learning. Not affiliated with or endorsed by Valve Corporation.

Does external mean approved?+

No. Some features automate actions through external inputs or scripts. Avoiding game-memory access does not guarantee permission or ban immunity. Use in official matchmaking may risk account bans at Valve’s discretion.

Where should I use it?+

Use it responsibly in appropriate settings, such as private servers or casual play, and follow the Steam Subscriber Agreement and CS2 rules. You are responsible for compliance; the developer is not liable for bans, data issues, or loss of functionality.

Does it change game files?+

ErScripts creates configuration files and sends commands through CS2’s exec system. It also receives GSI data and reads console logs. It does not read or write game memory or inject code.

What about fullscreen?+

The project’s guide says to leave “Disable fullscreen optimizations” unchecked in cs2.exe → Properties → Compatibility. See the current README and release notes for setup details.

Where can I get help?+

Check release notes and report reproducible problems on GitHub Issues. CS2 updates can change how command-based features behave.
